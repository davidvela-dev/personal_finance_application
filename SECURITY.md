# Security Policy

## Supported Versions

We only support and apply security patches to the **latest commit on the `main` branch**.

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability:

1. **Do NOT open a public issue.**
2. Submit a report via [GitHub Private Vulnerability Reporting](https://github.com/tu-usuario/tu-repositorio/security/advisories/new).
3. Include details, steps to reproduce, and potential impact.

Thank you for reporting responsibly!
